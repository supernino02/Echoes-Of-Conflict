# BUGBusters — Preliminary Version

This folder contains the assets, styling, and JavaScript logic for the **preliminary version** of the data visualization page. 

The single entry point for this version is `../old_website.html` (located in the root directory), which is not mobile-optimized and is intended to be seen on bigger screens.

Overview
- **../old_website.html**: The entry point that ties everything together. It loads the stylesheets and all the scripts inside `js/`, to render the visualizations.
- **assets/**: Contains GeoJSON files mapping the regions.
- **BACKEND_DATA/**: Directory with JSON data for multiple categories of visualization, maps, networks, etc.
- **css/**: Contains all the `.css` stylesheets specific to individual charts and global application stylings.
- **js/**: Contains the main JavaScript logic to build and interact with the data visualizations and charts (bar charts, maps, network charts, widgets, etc.).
